How It Works

Ready in 3 Steps

From download to shared shopping in under a minute.

1

Create a Room

Open List-e and tap "Create Room" to start a new shared list. You'll get a unique 6-digit code instantly.

2

Share the Code

Send the code to your partner, family member, or roommate. They enter it in the app and join your room.

3

Shop Together

Start adding items! Everyone in the room sees updates in real time. Check off items as you go.
